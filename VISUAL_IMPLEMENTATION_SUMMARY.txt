🗺️  CACHE STRATEGY MAP

  URL Request
	   ↓
   ┌──────────────────────────┐
   │  Static Assets? (JS/CSS)  │
   └──────────────────────────┘
			↙              ↘
		  YES              NO
		   ↓               ↓
   ┌──────────────┐   ┌────────────────────┐
   │Cache-First   │   │ Movie Image?       │
   │1-year expiry │   │(poster/backdrop)   │
   │(immutable)   │   └────────────────────┘
   └──────────────┘         ↙          ↘
						   YES         NO
							↓          ↓
					┌──────────────┐ ┌──────────────┐
					│Cache-First   │ │Network-First │
					│30-day expiry  │ │(APIs, etc)   │
					│(TMDB images) │ │Fallback cache│
					└──────────────┘ └──────────────┘
						   ↓               ↓
					Return cached    Try network →
					(instant load)   Fallback cache

🚀 DEPLOYMENT STEPS

WEBSITE (Firebase Hosting):
┌─────────────────────────────────────────────────────────┐
│ 1. Copy firebase.json to project root                   │
│ 2. Copy public/service-worker.js to public/ folder      │
│ 3. Copy public/sw-manager.js to public/ folder          │
│ 4. Add to index.html: <script src="/sw-manager.js"></script>
│ 5. Test: firebase serve                                 │
│ 6. Deploy: firebase deploy --only hosting               │
│ 7. Verify in DevTools: Application → Service Workers    │
└─────────────────────────────────────────────────────────┘
